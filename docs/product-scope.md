# 产品范围与 MVP 边界

## 产品范围

本项目是一款 Android 原生应用，围绕“耳机作为入口”提供语音记录、记忆管理和轻量数字员工能力。

首期范围包括：

- 四个品牌耳机兼容策略：`Huawei`、`Lenovo`、`Oppo`、`Honor`
- 耳机按键触发
- 手机快捷操作触发
- 会话级自定义触发词
- 录音、转写、摘要、待办结构化
- Markdown 记忆写入、检索、删除、导出

## MVP Non-Goals

首期不做或仅预留接口：

- iOS
- 小程序
- 24/7 常驻监听
- 系统级 always-on hotword
- 声纹绑定身份识别
- 自动发消息、自动外呼、自动执行高风险操作
- 厂商深度私有能力，例如固件升级、查找耳机、完整配对向导

## 为什么首期只做 Android

Android 更适合做首期落地，原因是：

- 原生 App 对前台服务、媒体会话、通知和录音流程的可控性更高
- 耳机按键和媒体控制事件的接入路径更清晰
- 相比 iOS，Android 更适合先验证“耳机入口 + 语音记忆”闭环
- 我们当前的产品目标是先验证可用性，而不是一次性覆盖所有平台

## 为什么触发词只做到会话级

这里的“会话级”指的是：用户先显式开启一个录音会话，之后在该会话内可通过自定义触发词继续触发动作或再次开始记录。

这样设计是为了：

- 避免把产品做成系统级 always listening
- 降低电量、后台和审核风险
- 让用户更容易感知“我现在正在录音/正在工作”
- 给第三方同意和隐私提示留出明确边界

我们保留“自定义触发词”能力，但不承诺系统级常驻热词唤醒。

## 交互原则

- 用户显式启动
- 录音状态显式可见
- 任何高风险动作二次确认
- 任何内容可删除
- 默认记忆可导出
