## 项目简介

`Coworker in Ears` 希望把耳机变成一个真正随身、免手持、低打扰的数字搭子。  
当用户在走路、通勤、开会间隙、灵感闪现的瞬间，都可以随时随地记录、整理、沉淀内容，而不用频繁掏出手机打断思路。

当前项目主线包括：

- 耳机按键触发记录
- 手机快捷操作触发记录
- 自定义触发词触发记录
- 语音内容结构化整理
- Markdown 记忆存储与归档
- 本地优先、用户可控的数据策略

## 当前范围
